# FrontHarness

FrontHarness — событийно-ориентированная CLI/TUI система для автоматизированной генерации и глубокого редизайна веб-интерфейсов. Инструмент написан на Rust с использованием фреймворка Ratatui и асинхронной среды Tokio. Архитектура объединяет изолированное агентное ядро Pi, терминальный интерфейс в стиле LazyVim, модуль взаимодействия с OpenAI-совместимыми LLM, браузерный краулер на Playwright, локальный MCP-мультиплексор и долговременную память на SQLite.

---

## Архитектура системы

1. **Ядро Pi и Event Bus**: Асинхронная шина сообщений (`tokio::sync::broadcast`), полностью отделяющая логику выполнения агентов от слоя терминального рендеринга.
2. **TUI интерфейс (LazyVim / OpenCode Style)**: Навигация исключительно с клавиатуры через Vim-биндинги, потоковый рендеринг генерации кода, просмотр диффов, логов и статус-строка.
3. **Multi-Provider LLM Engine**: Клиент для OpenAI-совместимых эндпоинтов с поддержкой автоматического обнаружения моделей (`/v1/models`), потоковой обработки SSE и нормализации параметров `reasoning_effort` (`low`, `medium`, `high`, `custom`).
4. **Браузерный инспектор и перехватчик ассетов**: Скрипт Playwright для снятия Desktop (1920x1080) и Mobile (375x812) скриншотов, извлечения Computed CSS и DOM-структуры, а также локального сохранения ассетов (SVG, шрифты, стили).
5. **Мультиагентный DAG оркестратор**:
   - **Research Agent**: Поиск паттернов дизайна и конкурентов через Tavily Search API.
   - **Art Director Agent**: Формирование дизайн-системы, токенов и макроструктуры (`design.md`).
   - **Implementation Agent**: Написание доступного и адаптивного HTML5/Tailwind/GSAP кода.
   - **QA & Browser Verification Agent**: Запуск локального dev-сервера и верификация интерфейса через Playwright.
6. **Матрица скилов**: Встроенные правила Hallmark (структурное разнообразие), Design Taste (настройка шкал и контраста), Stop-Slop (блокировка шаблонных градиентов и эмодзи) и Lucide SVG иконки.
7. **Долговременная память**: Хранилище SQLite для сохранения архитектурных решений, метрик и пользовательских оценок.

## Установка

Запустите установочный скрипт:

```bash
chmod +x install.sh
./install.sh
```

Или соберите проект вручную:

```bash
cargo build --release
cp target/release/frontharness ~/.local/bin/frontharness
ln -sf ~/.local/bin/frontharness ~/.local/bin/fh
```

### Системные требования
- Rust 1.80+ / Cargo
- Python 3.10+ с пакетом `playwright` (`pip install playwright && playwright install chromium`)
- Node.js (v18+)
- Git

## Конфигурация

Создайте файл `.env` в корне проекта или настройте `~/.config/frontharness/config.yaml`:

```ini
LLM_BASE_URL=https://agentrouter.org/v1
LLM_API_KEY=your_api_key
LLM_MODEL=gpt-5.6-sol
LLM_REASONING_EFFORT=high

TAVILY_API_KEY=your_tavily_key
DEV_SERVER_PORT=3000
BROWSER_HEADLESS=true
```

## Команды CLI

### 1. Редизайн и аудит сайта
Запуск полного цикла аудита и редизайна целевого ресурса:

```bash
frontharness audit --url https://as-chelyabinsk.ru/ --goal "Повысить читаемость и визуальный уровень, внедрить современные плавные анимации, сохранив исходную структуру и упростив конверсионный путь."
```

Запуск в фоновом режиме без TUI:

```bash
frontharness audit --url https://as-chelyabinsk.ru/ --headless
```

### 2. Генерация с нуля (Greenfield)
Создание нового интерфейса по текстовому описанию:

```bash
frontharness greenfield --goal "Создать B2B SaaS лендинг для платформы наблюдаемости с макроструктурой Bento Grid и темной темой."
```

### 3. Список доступных моделей
Запрос и вывод списка моделей с настроенного эндпоинта:

```bash
frontharness models
```

### 4. Просмотр настроек
Отображение текущей конфигурации:

```bash
frontharness config --show
```

## Горячие клавиши TUI

| Клавиша | Действие |
| --- | --- |
| `Tab` / `Shift+Tab` | Переключение фокуса между панелями (DAG, стрим, логи) |
| `j` / `k` или `Down` / `Up` | Прокрутка содержимого активной панели |
| `d` | Открыть окно просмотра диффов кода |
| `l` | Открыть окно системных логов и событий Event Bus |
| `a` | Открыть галерею ассетов и скриншотов |
| `m` | Открыть окно долговременной памяти и отзывов |
| `?` | Открыть справку по горячим клавишам |
| `Esc` / `q` | Закрыть модальное окно / Выйти из приложения |
