# FrontHarness

FrontHarness — событийно-ориентированная CLI/TUI система для автоматизированной генерации и глубокого редизайна веб-интерфейсов. Инструмент написан на Rust с использованием фреймворка Ratatui и асинхронной среды Tokio. Архитектура объединяет изолированное агентное ядро Pi, терминальный интерфейс в стиле LazyVim с интерактивным запуском пайплайна (`r`) и редактором настроек (`c`), модуль взаимодействия с OpenAI-совместимыми LLM, браузерный краулер на Playwright, локальный MCP-мультиплексор и долговременную память на SQLite.

## Как запускать и куда вводить промпты

Вы можете работать с FrontHarness двумя способами:

### Способ 1: Прямо из интерактивного TUI (Рекомендуемый)
1. Запустите `frontharness` (или `fh`).
2. Нажмите **`r`** (или `n`) на клавиатуре — откроется окно **Запуска нового пайплайна**.
3. Введите **URL целевого сайта** (например, `https://as-chelyabinsk.ru/`).
4. Нажмите **`Tab`** для перехода в поле **Промпта / Цели редизайна** и укажите задачи (например, `Сделать современный индустриальный дизайн, Bento-сетку, анимации GSAP и быстрый путь к заявке`).
5. Нажмите **`Enter`** — пайплайн сразу запустится, отображая прогресс в DAG и потоковую генерацию кода в реальном времени!

### Способ 2: Через команду в терминале (CLI)
- **Аудит и редизайн сайта**:
  ```bash
  frontharness audit --url https://as-chelyabinsk.ru/ --goal "Повысить читаемость и визуальный уровень, внедрить современные плавные анимации, сохранив структуру."
  ```
- **Фоновый режим без TUI**:
  ```bash
  frontharness audit --url https://as-chelyabinsk.ru/ --headless
  ```
- **Генерация с нуля (Greenfield)**:
  ```bash
  frontharness greenfield --goal "Создать B2B SaaS лендинг для платформы мониторинга с темной темой."
  ```

## Горячие клавиши TUI

| Клавиша | Действие |
| --- | --- |
| `r` / `n` | **Запустить новый пайплайн** (Открыть окно ввода URL и промпта) |
| `c` | **Редактор конфигурации** (API-ключи, модели, поиск, порты) |
| `Пробел` | Переключение опций в конфигураторе (Поисковик: `duckduckgo`/`tavily`, режим рассуждений, headless) |
| `Tab` / `Shift+Tab` | Переключение фокуса между панелями (DAG, стрим, логи) |
| `j` / `k` или `Down` / `Up` | Прокрутка содержимого активной панели |
| `d` | Открыть окно просмотра диффов кода |
| `l` | Открыть окно системных логов и событий Event Bus |
| `a` | Открыть галерею ассетов и скриншотов |
| `m` | Открыть окно долговременной памяти и отзывов |
| `?` | Открыть справку по горячим клавишам |
| `Esc` / `q` | Закрыть модальное окно / Выйти из приложения |
