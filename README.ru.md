# FrontHarness

FrontHarness — событийно-ориентированная CLI/TUI система для автоматизированной генерации и глубокого редизайна веб-интерфейсов. Инструмент написан на Rust с использованием фреймворка Ratatui и асинхронной среды Tokio. Архитектура объединяет изолированное агентное ядро Pi, терминальную дизайн-студию (`r`), интерактивную матрицу выбора скилов (`[x]`/`[ ]`), директивы стиля, аудит локальных сайтов, прикрепление референсов, модуль взаимодействия с LLM, браузерный краулер на Playwright и долговременную память на SQLite.

## Ключевые возможности

1. **Аудит удаленного URL или локальной папки**: Редизайн онлайн-ресурсов (`https://...`) либо прямой аудит локальной директории с `index.html`, стилями и картинками без интернета.
2. **Кастомная рабочая директория (Workspace)**: Сохранение сгенерированного кода, отчетов аудита и медиа в любую указанную папку на диске.
3. **Интерактивная матрица скилов (Skills Matrix)**: Выборочное включение обязательных правил с чекбоксами `[x]` / `[ ]`:
   - `Hallmark`: Структурное разнообразие макроструктур (Bento Grid, Workbench, Split Screen).
   - `Taste`: Шкалы плотности/анимаций, строгая палитра, контраст WCAG AA.
   - `Stop-Slop`: Блокировка шаблонных AI-градиентов и **полный запрет Unicode-эмодзи**.
   - `Motion`: Физика GSAP 3.12 ScrollTrigger и плавный скролл Lenis.
   - `Icons`: Векторные SVG-иконки Lucide.
   - `Modern Web`: Адаптивные сетки, clamp() масштабирование, container queries.
   - `Security`: Защита от XSS и безопасные атрибуты форм.
4. **Директивы стиля дизайна (Design Style Directives)**: Прямое указание желаемого визуального стиля (палитра, шрифты, настроение), которому нейросеть жестко следует.
5. **Прикрепление референсов**: Добавление ссылок на сайты-примеры (например, `https://linear.app`) или путей к локальным скриншотам/мудбордам.
6. **Выбор поисковика**: Бесключевой **DuckDuckGo** или **Tavily Search API**.
7. **Управление Reasoning Effort**: Автоматическое определение поддерживаемых уровней рассуждений модели (`low`, `medium`, `high`, бюджет токенов `2048`, `8192` и т.д.).

## Как запускать и использовать Design Studio

### Способ 1: Терминальная дизайн-студия в TUI (Рекомендуемый)
1. Запустите `frontharness` (или `fh`).
2. Нажмите **`r`** (или `n`) на клавиатуре — откроется окно **Design Studio & Pipeline Launcher**:
   - **1. Target Source**: Введите URL (например, `https://as-chelyabinsk.ru/`) или путь к локальной папке (например, `./my_site`).
   - **2. Workspace Output**: Укажите папку для сохранения результатов (например, `workspace` или `./dist`).
   - **3. Business Goal & Requirements**: Опишите цели и требования к сайту.
   - **4. Design Style Directives**: Задайте стиль (например, *«Темный графит, акцентный янтарь, шрифт Space Grotesk, Bento-сетка»*).
   - **5. Design References**: Укажите ссылки на референсы или пути к картинкам через запятую.
   - **6. Active Skills Matrix**: Перемещайтесь стрелками `Left`/`Right` (`h`/`l`) и нажимайте **`Пробел`** для включения/выключения скилов `[X]` / `[ ]`.
3. Нажмите **`Enter`** для запуска пайплайна!

### Способ 2: Через CLI в терминале
- **Аудит с кастомным стилем, референсами и скилами**:
  ```bash
  frontharness audit \
    --url https://as-chelyabinsk.ru/ \
    --workspace-dir ./output \
    --style "Темный индустриальный: графит #09090b, янтарь #f59e0b, Space Grotesk, Bento-сетка" \
    --references "https://linear.app, /path/to/moodboard.png" \
    --skills "hallmark,taste,stop_slop,motion,icons" \
    --goal "Повысить конверсию и внедрить интерактивную форму записи"
  ```
- **Аудит локальной папки сайта**:
  ```bash
  frontharness audit --local-dir /path/to/local/site --workspace-dir ./workspace
  ```
- **Фоновый режим без TUI**:
  ```bash
  frontharness audit --url https://as-chelyabinsk.ru/ --headless
  ```

## Горячие клавиши TUI

| Клавиша | Действие |
| --- | --- |
| `r` / `n` | **Дизайн-студия и запуск пайплайна** (URL/локальная папка, workspace, стиль, референсы, матрица скилов) |
| `c` | **Редактор конфигурации** (API-ключи, модели, поиск, порты) |
| `Пробел` | Переключение опций в конфигураторе и чекбоксов в матрице скилов |
| `Tab` / `Shift+Tab` | Переключение между полями ввода / панелями |
| `j` / `k` или `Down` / `Up` | Прокрутка содержимого активной панели |
| `d` | Открыть окно просмотра диффов кода |
| `l` | Открыть окно системных логов и событий Event Bus |
| `a` | Открыть галерею ассетов и скриншотов |
| `m` | Открыть окно долговременной памяти и отзывов |
| `?` | Открыть справку по горячим клавишам |
| `Esc` / `q` | Закрыть модальное окно / Выйти из приложения |
